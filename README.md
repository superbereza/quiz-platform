# Retro Quiz Platform

Квиз-платформа в духе 2005 года: создавайте вопросы с картинками, запускайте раунды и показывайте результаты друзьям в реальном времени.

## Возможности

- 🕹️ Панель ведущего с созданием вопросов (текст, ссылка на картинку и четыре варианта ответов).
- 📡 Живое управление ходом игры: запуск вопросов, показ результатов, финальная таблица.
- 👥 Игровая страница для участников — достаточно перейти по ссылке, ввести логин и выбирать ответы.
- 🏆 Мгновенная статистика после каждого вопроса с количеством правильных ответов и рейтингом игроков.
- 🏁 Финальные итоги после завершения квиза с определением победителей.
- 💾 Никакой базы данных — состояние хранится в памяти сервера, что упрощает деплой.

## Быстрый старт

```bash
npm install
npm start
```

Сервер поднимется на порту `3000`. Перейдите в браузере на `http://localhost:3000`:

- `/admin.html` — панель ведущего. Введите код квиза (например, `RETRO`), добавьте вопросы и управляйте раундами.
- `/play.html` — страница игроков. Передайте ссылку `http://localhost:3000/play.html?quiz=RETRO` друзьям: им останется только ввести логин.

## Как провести игру

1. Откройте `/admin.html`, придумайте короткий код (например, `RETRO`) и введите его в поле «Код квиза».
2. Нажмите «Подключиться». Если такого кода ещё не было, сервер сразу создаст новый квиз, а на странице появятся блоки для добавления вопросов и управления ходом игры.
3. Заполните текст вопроса, четыре варианта ответов и (при необходимости) ссылку на картинку, затем нажмите «Добавить вопрос».
4. Повторите предыдущий шаг для всех вопросов раунда.
5. Поделитесь кодом с друзьями — им достаточно открыть `/play.html`, указать код и ввести логин.
6. Когда все готовы, нажмите «Запустить следующий вопрос», чтобы отправить его игрокам. После закрытия вопроса используйте «Показать результаты», а затем переходите к следующему.
7. В финале нажмите «Финальная статистика», чтобы показать рейтинг победителей.

## Деплой

Приложение — обычный Node.js сервер, готовый к запуску на любой платформе, которая умеет стартовать `npm start` (Heroku, Render, Railway, CapRover и т.д.).

Для GitHub + CapRover:

1. Залейте репозиторий на GitHub.
2. На CapRover создайте новое приложение и укажите репозиторий.
3. Файл `captain-definition` уже содержит нужные команды (`npm install` и `npm start`), поэтому дополнительные настройки не требуются.
4. Задеплойте — после старта приложение будет доступно по адресу, который выдаст CapRover.

## Ограничения

- Данные квиза хранятся в оперативной памяти — после перезапуска сервера они сбросятся.
- Для одновременной игры большого числа команд рекомендуются сервера с достаточными ресурсами и хорошей сетью.
